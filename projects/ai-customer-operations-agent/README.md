# 🏢 AI Customer Operations Agent

An AI workflow engine for customer-support operations: classify requests, retrieve policy knowledge, draft responses, route complex cases and keep a human approval path.

## Workflow

`Message → Intent → Knowledge Retrieval → Action Plan → Policy Check → Human/Auto Route → Audit Log`

## Business value

- Ticket triage
- FAQ and policy answers
- Structured CRM updates
- Escalation detection
- Human-in-the-loop approvals
- Auditable tool actions

## Stack

Python · FastAPI · PostgreSQL · Redis · RAG · agent workflows
