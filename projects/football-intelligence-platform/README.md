# 🎥 Football Intelligence Platform

End-to-end football video analytics concept for detecting players and the ball, tracking movement and producing match-level metrics.

## Pipeline

`Video → Detection → Tracking → Team Assignment → Events → Metrics → API/Dashboard`

## Analytics

- Player and ball detection
- Multi-object tracking
- Speed and distance estimates
- Possession/event foundations
- Annotated replay generation

## Stack

Python · YOLO · OpenCV · tracking · FastAPI
